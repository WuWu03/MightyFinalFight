### FC快打旋风Unity重制版
![](/desc.png)

本项目是使用Unity开发的FC快打旋风重制版
仅开发了第一关可玩内容，以开发Unity基础框架为主要目的
项目开发规范由我写的框架<WuWuFramework>严格框定，包括但不限于各种路径，文件的格式、名称，应用程序、游戏对象的生命周期（当然，具体的工程结构框架也给出了配置项，可以自由配置）

项目含有完整的框架和工具链，包括： 
1. MVP模式UI框架及常用UI工具
2. 行为树及编辑器
3. 类型安全的事件框架
4. 状态机
5. 资源管理及AB打包工具
6. 配置数据管理及[Excel导出工具](https://github.com/WuWu03/ExcelExport)
7. 场景管理
8. 音频管理
9. 游戏对象管理
10. 资源下载更新
13. 多语言
14. 各种池

以及一个还算完善的2.5D横板Demo
