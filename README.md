### FC快打旋风Unity重制版
本项目是使用Unity开发的FC快打旋风重制版
仅开发了第一关可玩内容，以开发Unity基础框架为主要目的
项目含有完整的框架和工具链，包括：
1. UI框架及常用UI工具
2. 横板2.5D游戏基本框架
3. 地图编辑器
4. 行为树及编辑器
5. 事件框架
6. 技能编辑器
7. 状态机
8. 资源管理
9. 数据管理
10. 场景管理
11. 游戏对象管理
12. 音频管理
13. 资源下载更新
14. 多语言
15. 各种池
